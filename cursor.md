# Refract models in Cursor

1. Open **Settings**, then **Models**.
2. Under API keys, turn on **OpenAI API key** and paste your `rf_…` key.
3. Turn on **Override OpenAI base URL** and enter `https://refracthub.com/v1`.
4. Add a custom model, for example `refract/claude-opus-5-5`, then pick it in the chat.

Want more or less thinking? Add `-low`, `-medium` or `-high` to the name, like `refract/claude-opus-5-5-high`. Same model, same price.

All model IDs: https://refracthub.com/models
